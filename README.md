# Customer Shopping Behaviour 📊🛍️

A small end-to-end analytics project exploring **customer shopping behaviour** using:

- **SQL** (business questions + answers)
- **Power BI** (interactive dashboard)
- **Python (Jupyter Notebook)** for quick exploration/validation
- A CSV dataset of ~3.9K customer purchase records

---

## Project Overview

This project analyses customer purchase patterns to answer questions such as:

- Do **male vs female** customers generate different revenue?
- Do customers who use **discounts** still spend above average?
- Which products have the **highest review ratings**?
- Does **shipping type** influence average spend?
- Do **subscribers** spend more than non-subscribers?
- Which products have the **highest discount rate**?
- Customer segmentation: **New / Returning / Loyal**
- Top purchased products per category
- Are repeat buyers more likely to subscribe?
- Revenue contribution by age

## Dataset

Typical fields:
- `id`, `age`, `gender`
- `category`, `item_purchased`
- `amount` (Purchase Amount USD)
- `review_rating`
- `subscription_status`
- `shipping_type`
- `discount_applied`
- `previous_purchases`
- plus: location, size, color, season, payment method, frequency, etc.
